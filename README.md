# TwistTutor: Cube Solver

Minimal SwiftUI iOS app scaffold. Product features and design await the upcoming specification.

- Display name: `TwistTutor: Cube Solver`
- Bundle identifier: `com.serendipitylabs.twisttutor`
- Xcode project and scheme: `TwistTutor`
- Deployment target: iOS 17.0
- Devices: iPhone and iPad

Open `TwistTutor.xcodeproj` in Xcode. Select a simulator and run the `TwistTutor` scheme. For a physical device, select your Apple development team under Signing & Capabilities.

The initial screen contains only the app name and a system cube symbol. App icons, product functionality, and release configuration will follow the specification.
